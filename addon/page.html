    Make your own reporter
    
Any machine can post its own report every 5 minutes. Send JSON to /report on port 8790
      (http://homeassistant.local:8790/report):

    
{
  "machine": "example", "name": "Example machine", "kind": "linux",
  "metrics": {"cpu": 12.5, "mem": 40, "disk_used_pct": 55},
  "counters": {"disk_read_bytes": 1000000, "disk_write_bytes": 2000000,
               "net_rx_bytes": 3000000, "net_tx_bytes": 4000000},
  "cpu_ticks": [1000, 500],
  "problems": {}
}

    
machine is the id a check watches (lowercase letters, digits, hyphens); name and
      kind are labels. metrics holds the numbers shown on the page. counters are
      raw totals since boot: Home Watch works out the amounts from one report to the next. cpu_ticks is
      [total, idle]. Put anything only the machine can see in problems (a drive health warning,
      for example) and it shows as a problem on the page.

    
curl -X POST http://homeassistant.local:8790/report -H "Content-Type: application/json" \
  -d '{"machine":"example","name":"Example machine","kind":"linux","metrics":{"cpu":12.5,"mem":40},"counters":{},"cpu_ticks":[1000,500],"problems":{}}'
